# BrightTV User Behavior Analysis

## 📌 Objective
This project analyzes BrightTV user viewing behavior to identify usage trends, key drivers of consumption, and provide data-driven recommendations to improve user engagement and increase subscriptions.

---

## Tools Used
- Databricks SQL (Data cleaning & transformation)
- Microsoft Excel (Analysis & visualization)
- Miro (Project planning)
- Gantt Chart (Timeline planning)
- PowerPoint / Canva (Presentation)

---

## Project Structure

### 1. Project Description & Raw Data
Contains the case study document and original datasets used for analysis.

### 2. Project Planning
Includes project planning materials such as workflow design, Miro boards, and Gantt charts outlining the project timeline and approach.

### 3. Data Processing
Includes SQL scripts used for data cleaning, transformation, and feature engineering.

### 4. Excel Analysis
Contains the cleaned dataset, PivotTables, charts, and dashboard used to analyze user behavior.

### 5. Project Presentation
Contains the final presentation slides summarizing insights and recommendations.

---

## Key Analysis Performed
- Viewing trends by day, time, and hour
- User segmentation by age, gender, and province
- Content performance analysis
- Identification of low-consumption days
- Strategic recommendations for growth

---

## Key Insights
- Peak viewing occurs during evening hours
- Certain age groups drive the majority of engagement
- Specific content categories dominate user preference
- Low-consumption days present opportunities for targeted strategies

---

## Recommendations
- Promote top-performing content on low-consumption days
- Target high-engagement age groups with personalized marketing
- Optimize content scheduling during peak hours
- Expand reach in high-potential regions

---

## Conclusion
This project demonstrates how data analytics can be used to understand user behavior and support strategic decision-making for digital platforms like BrightTV.
